| PROCESO DE DEFINICIÓN DE ALCANCE: DESCRIPCIÓN DETALLADA DEL PROCESO PARA ELABORAR EL ENUNCIADO DEL<br>Alcance Definitivo a partir del Enunciado del Alcance Preliminar. Definición de qué, quién, cómo, cuándo, dónde, y con qué. |
|---|
| Qué: delimitar la captura, IA y trazabilidad; quién: PM y analista funcional; con qué: acta y RF/RNF. |
| Cómo: analizar AS-IS/TO-BE, restricciones, interesados, requisitos y pruebas. |
| Cuándo: iniciación y refinamientos de sprint; dónde: sesiones de trabajo y campo de Agrícola Riachuelo. |
| Salida: enunciado aprobado con entregables, exclusiones, criterios y límites del piloto. |
| Nota: Adjuntar flujograma de procedimiento. |
| PROCESO PARA LA ELABORACIÓN DE LA EDT: DESCRIPCIÓN DETALLADA DEL PROCESO PARA CREAR, APROBAR, Y MANTENER LA EDT. DEFINICIÓN DE QUÉ, QUIÉN, CÓMO, CUÁNDO, DÓNDE, Y CON QUÉ. |
| Qué: descomponer producto en paquetes controlables por fase; quién: PM y especialistas de componentes. |
| Cómo: codificación WBS 1.0-5.0, productos verificables y criterios por paquete. |
| Dependencias: hardware → captura → IA y web → integración → piloto. |
| Validación: consenso técnico y conformidad del patrocinador operativo. |
| Nota: Adjuntar flujograma de procedimiento. |
| PROCESO PARA ESTABLECER LA LÍNEA BASE DEL ALCANCE: Descripción detallada de cómo se va a establecer, aprobar y mantener la Línea Base del Alcance |
| Línea base = enunciado del alcance + EDT + diccionario, con versiones congeladas. |
| Revisar variaciones semanalmente y al cierre del sprint. |
| Todo pedido nuevo requiere registro y evaluación de plazo, costo, seguridad y pruebas. |
| Solo se reemplaza la versión vigente con aprobación y comunicación trazable. |
| Nota: Adjuntar flujograma de procedimiento. |
| PROCESO PARA LA ACEPTACIÓN DEL ALCANCE: DESCRIPCIÓN DETALLADA DEL PROCESO PARA LA ACEPTACIÓN formal de los entregables por parte del cliente (interno o externo). Definición de qué, quién, cómo, cuándo, dónde, y con qué. |
| Entregar evidencia y resultados de pruebas vinculados a criterios de aceptación. |
| Especialista valida decisiones fitosanitarias; Jefe de Fundo valida uso operativo. |
| Registrar observaciones, defectos, responsable y fecha de corrección. |
| Emitir acta de aceptación sin confundir entrega técnica con aprobación formal. |
| Nota: Adjuntar flujograma de procedimiento. |
